# 📰 Fake News Detection

This project aims to automatically classify news articles as **fake** or **real** using **NLP techniques**.  
It compares the performance of **classic machine learning models** and **large language models (LLMs)**.

## 🎯 Goals

- Develop an automated tool to detect fake news with minimal human intervention.
- Achieve at least **80%** accuracy, recall, and precision.
- Analyze **linguistic patterns** common in fake news.
- Ensure **explainability** using tools like **LIME** and **SHAP**.

## 🛠 Tools & Resources

- **Hugging Face Transformers**, **scikit-learn**, **spaCy**
- **Kaggle dataset** (can be found under the `data_sample` folder)
- **Python** environment with standard NLP libraries

## 🔮 Future Work

- Extend the model to power a **browser plugin** that classifies news articles in real time.
- Add a **confidence score** indicating the reliability of each article.
- Provide value to **readers, journalists, and researchers** through fast, model-based insights.
- Combine multiple methods to improve real-world accuracy and robustness.
